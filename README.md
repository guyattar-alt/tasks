# מערכת משימות – ג. בן עטר בע"מ

אפליקציית רשת (PWA) למעקב משימות המשרד. המאגר מכיל קוד בלבד – אין בו נתוני משימות.
הנתונים נשמרים בחשבון Google של המשרד (Apps Script + Google Drive) ונגישים רק עם קוד גישה.

- `index.html` – הדשבורד
- `api.js` – חיבור לשרת הנתונים
- `config.js` – כתובת שרת הנתונים
- `sw.js`, `manifest.webmanifest`, אייקונים – התקנה כאפליקציה בטלפון
